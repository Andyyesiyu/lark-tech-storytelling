# lark-tech-storytelling

飞书文档（Docx / Wiki）技术写作与交互式图表指南 Skill（默认替代原生 `lark-doc` / `lark-cli` 内置文风与创建工作流）。

## 设计理念

1. **顺应主题本色的自适应叙事**
   - 根据文章想表达的内容自然选择脉络：**单个机制拆解**、**版本迭代与性能优化**（如推理引擎 `v1.1 → v1.4` 逐步演进与空闲气泡压缩）、**架构选型权衡**或**问题排查复盘**，无需强凑二元对比或故障冲突。
   - 正文与 SVG 配色自然呼应（Inline Color Cues），省去重复正文的冗长说明框。
   - 坚持平实直白的日常工程用语，保留顺口的英文术语（如 `Prefill`、`Decode`、`Steer`、`KV Cache`），禁用生硬直译与自造汉字黑词（如用「基线用例 / 问题用例」替代「黄金锚点 / 双桶」，用 `Steer` 或「修正方向」替代「定偏方向」，用「已拒绝记录」替代「负反馈账本」）。
2. **让图形结构贴合机制本身**
   - 根据机制特点选用直观画法：容量槽拼装与页表网格、GPU 时序甘特图与气泡压缩、版本切换 + 参数滑块、指针切换与存量连接排空、队列滑动与校验拦截，以及涉及并发状态流转时的业务状态流转图、`[前置条件]` 标签与最短复现路径高亮。
3. **纯白无界画布 × 恒定视图高度 × 舒缓手动调节**
   - 纯白 `#FFFFFF` 无外框设计自然融入飞书亮色正文；固定动态文案高度并锁定外层容器高度，确保动画播放、版本切换与控件交互期间单个 HTML 视图高度恒定不变，避免飞书文档上下晃动。
   - 默认采用 `16s～20s` 舒缓节奏（高信息量图表可默认暂停），配备 `◀ 上一步` / `▶/⏸` / `下一步 ▶`、可拖拽进度条、`0.5× / 1.0× / 1.5×` 倍速切换、阶段切换按钮与鼠标悬停关联高亮。

## 目录结构

- [`SKILL.md`](SKILL.md)：自适应叙事脉络、常见图形画法参考、纯白无界画布与舒缓手动交互设计建议。
- [`assets/interactive-svg-template.html`](assets/interactive-svg-template.html)：`<html5-block>` 参考蓝本（纯白无界画布 + 自适应单机制/版本演进/对比场景 + 手动慢速控制栏 + 负载参数滑块 + 悬停关联高亮）。
- [`assets/demos/`](assets/demos/)：精选的「飞书正文 + 内嵌交互图表」完整示例集（涵盖单机制拆解、版本迭代、指针切流、队列错位拦截及三类 Statechart 状态流转画法）。
