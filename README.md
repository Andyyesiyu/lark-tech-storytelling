# lark-tech-storytelling

飞书文档（Docx / Wiki）技术叙事与概念同构交互式可视化指南 Skill（默认替代原生 `lark-doc` / `lark-cli` 内置文风与创建工作流）。

## 设计理念

1. **顺应主题本色的自适应叙事**
   - 根据文章想表达的内容自然选择脉络：**单机制深度解剖**、**渐进版本迭代与性能优化**（如推理引擎 `v1.1 → v1.4` 阶梯演进与气泡收敛）、**架构选型权衡**或**问题排查复盘**，无需强凑二元对比或故障冲突。
   - 正文与 SVG 共享轻量的色彩语义呼应（Inline Color Cues），省去重复正文的厚重说明框。
2. **贴合机制的具象视觉母题**
   - 让图形几何匹配概念本身：卡槽装填与离散页表网格、GPU 时序甘特与气泡压缩、版本演进阶梯 + 参数滑块、指针拨动与存量水位排空、传送履带与闸门配对。
3. **纯白无界画布 × 恒定视图高度 × 舒缓手动调节**
   - 纯白 `#FFFFFF` 无外框设计自然融入飞书亮色正文；固定动态文案槽高并锁定业务容器高度，确保动画播放、版本切换与控件交互期间单个 HTML 视图高度恒定不变，避免飞书文档上下晃动。
   - 默认采用 `16s～20s` 舒缓节奏（高信息量图表可默认定格），配备 `◀ 上一步` / `▶/⏸` / `下一步 ▶`、无级拖拽进度条、`0.5× / 1.0× / 1.5×` 倍速切换、阶段胶囊与悬停聚光灯。
